appsall - A master executable directory for Arch based on fzf, shows every bin file on the system with a description of what it does exactly.


bashirc - A very basic telnet based IRC client, set to work with OFTC out of the box.


camcord - A desktop screen recorder for sway/wayland, can output gif or mp4, can do region or fullscreen.


catchat - A basic netcat based chat client, uses direct ip to ip communications.


charmapme - a basic character map with tui interface.


cpuey - a basic tui driven CPU/GPU governor config program.


dex - simple wrapper for LSD to launch it with clean settings for viewability.


drive-manager - tui based drive mounting/umounting, uses udisks interface and fzf for the gui, works with usb devices too.

equalizer - really basic fzf gui for the pipewire text based equalizer (you must enable the actual equalizer to use it).


event-viewer - a systemwide event viewer that can sort based on errors or warnings, with full color support.


ffmpeg-tui - basic frontend for ffmpeg, supports video or audio, has special profiles to make MacOS 7.6.1 compatible videos.


fido - basic wrapper for fzf file searching system-wide.
fontview - tui based font viewer.


lowercaser - basic utility to make all files in the executed directory lowercase (useful for dealing with wine stuff).

pacmanlog/lite - pacman log viewer program, the lite version shows only the biggies like removals or errors, etc.


pacmaster - tui frontend for pacman for full package management and maintenance/cleaning.


scanman - untested frontend for sane, tui driven.


sysinfo/b/c - the first two are wrappers for inxi and hwinfo, the c variant is a full tui alternative to hardinfo2, with benchmarking capability.


tuiparted - basic tui program for doing disk partitioning and formatting, has support for setting up esp partitions also.


tuipdf/tuicomic - really, really basic pdf/comic viewer, turns pdfs into png images for viewing.


txt2word - can process a .txt file into a .rtf file, while allowing line by line font substitutions.


macpdf - converts a pdf to 1990's MacOS 7 capable PDFs.
